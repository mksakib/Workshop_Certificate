About the project

Restoring independence with a locally made prosthetic hand

Most amputees in Bangladesh cannot afford imported prosthetic devices. This project develops a cost-effective myoelectric prosthetic hand that can grasp, point and hold objects — manufactured with local materials and 3D printing so it stays affordable, repairable and suited to local conditions.

Specific objectives

EMG acquisition

A robust, low-noise electromyography signal acquisition system built with locally sourced components.

Gesture intelligence

A machine learning model for intended hand-gesture recognition, deployed on a microcontroller for real-time control.

3D-printed hand

A lightweight, durable and affordable prosthetic hand using 3D printing, sensors and servo motors.

Field validation

Testing with amputees in Bangladesh for usability, comfort and everyday functionality.

Deliverables

  • 1Prototype of the EMG acquisition system
  • 2Microcontroller-based EMG gesture control system
  • 3Functional 3D-printed myoelectric prosthetic hand
  • 4Usability, comfort and functional test reports
